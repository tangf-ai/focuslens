# 专注镜 v0.4.1 · 自动活动日志与未识别统计修复（试用版）

版本：0.4.1 / build 22。Apple 芯片（arm64），macOS 14+。

## 从 v0.3.2 升级的主要变化

本次公开包同时包含此前仅在本机安装的 v0.4.0 自动活动日志改版，以及 v0.4.1 未识别统计修复。

- 主流程统一为「今天、时间线、时间洞察、设置」。自动记录前台窗口活动，展示估算时长；移除手动计时、目标、打分、结束反馈和手动复盘入口，不再要求确认或补填空闲。
- 轻量活动浮窗展示当前活动和估算分钟数，保留暂停、隐藏及多屏位置恢复，不再显示倒计时圆环。
- 时间线只读，相邻同应用、同类别、同未识别原因的片段合并显示，不跨空白时段。周洞察未来日期留空，不计算效率分或完成率。
- 个人活动说明自动保存；无操作检测仍支持通用 5 分钟、阅读 15 分钟、视频 30 分钟及自定义策略。恢复操作后继续记录，空闲不自动补记。
- 新增独立授权的文字自动小结，默认关闭。每天首次打开「今天」、12:30、18:30 按需更新，最多 3 次；只发送活动文字，不重新发送历史截图，失败保留旧结果。

## 未识别统计修复

```text
新活动
  -> 等待识别
      -> 同一窗口、5 秒内截图、明确分类成功：吸收本次短等待
      -> 中途切换或长等待：保留等待识别
      -> 捕获、网络或返回异常：识别异常
      -> 模型拿不准：证据不足
```

- 时间分布、详情和浮窗分别展示「等待识别」「识别异常」「证据不足」「历史未识别」，所有时长仍计入总量，不通过隐藏失败来降低占比。
- 不跨应用、窗口、日期、离线间隔、异常、低置信度、历史或人工记录回填。不根据应用名称套用缓存类别。
- 同一应用换前台窗口时也隔离迟到响应；取消不记成接口失败。
- 失败按 5 / 10 / 20 / 40 / 60 秒退避重试，上限不超过用户原采样间隔，仍保持单任务、不堆积请求。
- 本机保留最近 200 次脱敏诊断，只有时间、阶段、结果及错误/取消码，无截图、窗口标题、应用名、接口地址、密钥、响应正文或原始错误描述。诊断不向模型发送、不纳入活动导出。

## 升级与数据安全

- 首次升级到自动日志的数据格式前，先备份整套本机记录与配置。旧手动记录、标签、反馈和复盘保留为只读归档，不混入自动时长；旧进行中轮次停止并归档，不虚构完成情况。
- 旧未确认空闲不自动补记。此前明确确认但因崩溃未落盘的决定仍幂等恢复。
- v0.4.1 不批量重分类旧记录；只根据明确的旧占位/异常标题进行显示分组，无法确定来源的保留历史未识别。累计未知时间不会被清空。
- 本机数据位于 `~/Library/Application Support/FocusLens/`，密钥独立保存在 macOS 钥匙串。降级到旧数据格式前，应先备份现状，再恢复整套迁移备份，不要混写新旧格式。
- 清除自动活动仍需确认且先备份，保留旧归档；备份保留原数据，不等于安全擦除，也不删除服务端数据。
