# 专注镜 · FocusLens 0.1.5

轻量的 macOS 原生专注计时工具，支持置顶倒计时浮窗、本地专注记录和手动 AI 复盘。使用 SwiftUI / AppKit，无第三方依赖。

- 紧凑的浅色主题、可选目标、专注与休息计时。
- 自定义专注标签，支持新增、编辑、删除和无标签计时。
- 320 × 168 点的置顶小浮窗，支持拖动、暂停、继续和返回主窗口。
- 本地保存目标反馈、完成情况和专注自评分，支持统计、搜索和 JSON 导出。
- 接入自选的 Chat Completions 兼容服务，手动生成每日 / 每周复盘。
- 空闲不做秒级轮询；运行时只刷新可见的倒计时区域。

本轮目标为选填，留空即可开始；未填写的目标不用于推测任务内容。本项目独立实现，不读取或修改 Flow 的程序和数据。

## 直接使用

当前打包应用适用于 Apple 芯片 Mac（arm64），macOS 14 或更新版本。

1. 从本仓库 **Releases** 下载「FocusLens-macOS.zip」，解压后打开「专注镜.app」。如需长期使用，可以将它拖入「应用程序」文件夹。也可以按下方说明从源码构建。
2. 在「专注计时」本轮目标可选填；留空也可直接开始。选择任务类型和时长，点击「开始专注」。
3. 开始后自动显示 320 × 168 点的置顶小浮窗，位于屏幕右上角，可拖动。新版放大了时间数字，底部色条随剩余时间逐渐缩短，并显示剩余百分比；暂停时颜色变淡且进度停止。主窗口最小化或切到其他应用时，浮窗继续显示剩余时间。可在浮窗暂停 / 继续、返回主窗口；点击右上角叉号仅隐藏浮窗。
4. 主界面「小浮窗」按钮或菜单「专注 → 显示倒计时浮窗」（⌘⇧M）可重新显示。浮窗在到期后显示 00:00 和结束状态，保存反馈后收起。休息结束状态保留至手动隐藏。
5. 可暂停、继续或提前结束。点击「专注模式」进入大号全屏倒计时。
6. 结束后选择完成 / 部分完成 / 未完成。评分、备注可选，然后保存。
7. 在「本周统计」看时间、完整完成率、中断和评分，在「专注记录」搜索、查看和导出。

这是一份本地开发、临时签名的试用版，未进行 Apple 公证或 App Store 发布。

## 标签管理

计时页的「管理标签」或设置里的「专注标签 → 管理标签」都可以新增、编辑和删除标签。

- 名称为 1–20 个字符，重名会提示；新增后自动选中，下次启动也会保留选择。
- 改名同步到相关历史记录、正在进行的轮次和统计；已有 AI 复盘保留原文并提示记录发生变化。
- 删除只移除可选标签，历史记录保留原名称和时间；标签全部删除后仍可选择「无标签」计时。
- 专注记录支持按目标、标签或反馈搜索，统计也包含已删除标签的历史记录。

主窗口默认 960 × 680，侧栏、倒计时和页面留白已收紧；首次使用新版会调整一次窗口大小，之后可以自行调整。

## 浅色主题与资源策略

整个应用固定使用浅色主题，包含侧栏、主区域、设置和反馈弹窗。使用原生 SwiftUI，无内嵌浏览器或本地大模型进程。

空闲及暂停时不做秒级轮询；只有对应的倒计时画面可见时，局部计时每秒更新一次。浮窗通过原生 AppKit 标签直接更新文字，主窗口最小化后只刷新浮窗。隐藏或完全遮挡窗口时停止其画面刷新；到期完成仍由单次定时器负责。应用激活、唤醒和本地日期变更时重新校准。

取消了进度环的持续插值动画。记录只在开始、暂停、完成或保存等状态变更时写入，不会每秒保存。AI 仍为手动请求。

资源实测见 [资源检查](资源检查.md)，功能验证见 [验证记录](验证记录.md)；数值为本机短时采样，不代表所有设备或长期使用的上限。

## AI 复盘

在「设置」填写：

- 接口基础地址：例如你自己的 `https://服务域名/v1`，也支持完整的 `/chat/completions` 地址。
- 模型名称：由你所使用的服务提供；未预设或自动选择模型。
- API 密钥：保存在 macOS 系统钥匙串中。免鉴权本地接口可留空。

保存后进入「AI 复盘」，选择今天或本周，点击生成。请求使用 OpenAI 兼容的 Chat Completions 格式，包含 `model`、`messages`、`stream: false` 和 `max_completion_tokens: 1800`；服务和模型需要支持这些参数。仅支持返回文字的非流式响应。远程服务建议使用 HTTPS。

生成时仅发送所选日期范围的目标、任务类型、时长、中断次数、完成情况、评分和反馈。不会上传屏幕、文件或其他应用使用记录；不会后台自动请求。复盘会保存到本地，历史菜单可查看最近 50 份。

样本少于 7 个有记录日期或 20 轮时，提示模型只做初步观察；这些是提示约束，不能保证模型始终遵守，仍需核对输出。时长不直接转换为“效率分数”。

真实 AI 服务尚未配置，未进行真实模型调用。已通过模拟接口验证请求、返回显示和保存；不代表任何具体供应商已完成兼容性验证。官方 API 文档页访问受限，接口实现以模拟契约测试为当前验证依据。

## 时间和统计口径

- 计时依据实际经过时间，不依赖计时器回调次数；暂停时间扣除。
- 关闭应用、电脑睡眠期间，未暂停的时间仍会计入，最多计至本轮计划时长。离开工作前请先暂停。
- 专注模式仅操作本应用窗口全屏。结束时退出由本应用开启的全屏，不修改系统勿扰或通知设置，不播放声音。
- 不会自动开始休息或下一轮。休息不进入专注统计。
- 专注记录在保存结束反馈后才进入统计。待反馈状态会保存，重启后可继续填写。
- 按本机时区、每轮开始日期归属；跨日记录全部计入开始日。本周固定周一至周日。
- 完整完成率 = 选择“完成”的轮数 / 全部已保存轮数。“部分完成”不视为完整完成。
- 中断 = 手动暂停次数；不推断用户离开座位或使用其他应用。
- 自评分为主观的 1–5 分，未填写的轮次不参与均值。
- AI 是生成时的快照；范围内新增或删除记录后，当前复盘会提示更新。

## 本地数据

默认位置：`~/Library/Application Support/FocusLens/focus-data.json`。v0.1.5 兼容旧版记录，首次读取旧数据时会保留 `focus-data-before-v2.json` 备份；首次保存后写入支持自定义标签的数据格式。v0.1.4 等旧版不能直接读取新版格式，回退时应先另存当前记录，再使用升级前备份。记录和复盘以本地 JSON 保存；密钥不写入 JSON。设置中可打开文件夹、导出全部记录。

原文件无法读取或版本不支持时，应用停止覆盖写入以保护文件。可以先备份数据文件再检查。导出的 JSON 包含目标和反馈，分享前请自行检查内容；导出只用于查看或备份，本版没有导入恢复界面。删除单条记录不可撤销。

本版不包含 Flow 历史记录导入、系统级网站/应用屏蔽、勿扰联动、跨设备同步或自动 AI 推送。

## 源码与构建

需要 macOS 和 Apple Command Line Tools（`xcode-select --install`）。无第三方依赖。

在项目目录运行：

```sh
./scripts/test.sh
./scripts/build-app.sh
```

默认在项目的上一级目录生成「专注镜.app」。指定输出和编译缓存位置：

```sh
./scripts/build-app.sh /绝对路径/交付目录 /绝对路径/编译缓存
```

`test.sh` 直接编译核心逻辑与自包含检查器，不依赖完整 Xcode 的 XCTest。20 项检查覆盖计时、持久化、统计边界、异常文件和 AI 请求响应。Intel Mac 可在对应机器上重新构建；当前交付二进制仅验证 arm64。

隔离界面测试可以启动独立数据目录：

```sh
open -n /绝对路径/专注镜.app --args --data-directory /绝对路径/测试数据目录
```

避免同时启动多个实例写入同一个目录。隔离参数仅隔离记录及配置文件；API 密钥仍由同一系统钥匙串条目管理，测试时不要修改正式密钥。
